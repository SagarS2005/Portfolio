About

The short version, and the timeline it's built on.

I'm a developer based in Raipur, Chhattisgarh, currently pursuing an MCA in Full-Stack Development at Rungta International Skill University. My focus is the MERN stack — React on the front end, Node/Express and MongoDB (alongside PostgreSQL, MySQL, and Oracle SQL) on the back — with Java and C++ underneath for data structures and problem solving.
